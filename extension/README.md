# HE Suite — Tab Session Bridge (Chrome Extension)

Extension ringan untuk menghubungkan tab browser yang sedang kamu gunakan langsung ke HE Suite, sehingga kamu bisa mengevaluasi halaman yang membutuhkan login/captcha tanpa copy-paste cookie manual.

---

## ⚡ Cara Pasang di Google Chrome / Edge / Brave (15 Detik)

1. Buka browser, lalu buka URL:
   👉 **`chrome://extensions/`** (atau `edge://extensions/` jika pakai Edge).
2. Aktifkan saklar **"Developer mode"** di pojok kanan atas.
3. Klik tombol **"Load unpacked"** di pojok kiri atas.
4. Pilih folder:
   👉 `C:\Users\game\Desktop\hesuite\extension`
5. Selesai! Extension langsung aktif.

---

## 🚀 Cara Pakai di HE Suite

1. Buka website target di tab browser kamu (misal `https://tokopedia.com` atau `https://shopee.co.id`) dan lakukan login.
2. Buka tab HE Suite (`http://localhost:8888`).
3. Di panel **SESI & AUTH INJECTION**, klik tombol **`[ 🔍 DETEKSI TAB BROWSER ]`**.
4. Pilih tab website yang sedang kamu buka dari dropdown.
5. Selesai! Cookie sesi otomatis terserap ke evaluasi tanpa copy-paste manual.
